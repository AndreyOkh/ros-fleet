# Memory Bank File Structure & Content Guide

Каждый файл в `.agents/memory-bank/` выполняет строго определенную функцию:

| Файл | Назначение | Когда читать | Когда обновлять |
| :--- | :--- | :--- | :--- |
| `projectbrief.md` | Фундамент проекта: цели, назначение, ключевые метрики. | При старте проекта или для понимания глобальных целей. | При изменении концепции или глобальных целей проекта. |
| `productContext.md` | Продуктовый контекст: решаемые проблемы, UX, пользовательские сценарии. | При разработке фич и пользовательских сценариев. | При добавлении новых пользовательских возможностей. |
| `systemPatterns.md` | Архитектура, ключевые паттерны, структура модулей, соглашения по коду. | Перед проектированием и реализацией кода. | При изменении структуры модулей или принятии решений. |
| `techContext.md` | Стек технологий, зависимости, окружение, запуск, сборка. | При работе со сборкой, зависимостями, конфигами. | При обновлении версий, зависимостей или способов запуска. |
| `activeContext.md` | Текущий контекст: недавние правки, фокус, следующие шаги. | **Обязательно при начале каждой сессии/задачи.** | **После выполнения каждого шага или задачи.** |
| `progress.md` | Статус готовности: выполненные задачи, backlog, известные проблемы. | Для оценки прогресса и выбора следующей задачи. | После завершения фичи, фикса багов или нахождения проблемы. |
