# Project Progress

## Implemented & Working Features
- [x] **Ядро Go 1.27.4 + encoding/json/v2**: переход на современный Go тулчейн и стандартный JSON v2.
- [x] **SSH/SFTP драйвер MikroTik**: поддержка RouterOS v6 и RouterOS v7 (`show-sensitive`, `dont-encrypt`).
- [x] **Раздельное хранение бэкапов**: `binary/` (файлы `.backup`) и `exports/` (файлы `.rsc`).
- [x] **Git-интеграция**: автоматическая нормализация дат в заголовках, единый коммит по итогам прогона, `git push`, поддержка отправки через Access Token (GitHub, GitLab, Gitea, Bitbucket) и маскирование секретов `[REDACTED]`.
- [x] **Ротация архивов**: автоматическое удаление бинарных бэкапов старше `retention_days`.
- [x] **Time-of-day планировщик**: запуск в заданные часы с учетом часовых поясов.
- [x] **Персистентность (`state.json`)**: потокобезопасное хранение истории бэкапов и метрик устройств с атомарной записью и поддержкой Docker bind-mount (`EBUSY` fallback).
- [x] **Web UI на HTMX**:
  - Адаптивный дашборд с темной/светлой темой.
  - Управление роутерами (добавление, редактирование, удаление).
  - 3-позиционные овальные переключатели наследования дефолтных настроек с подсказками по умолчанию под кнопками.
  - Панель быстрой мульти-фильтрации устройств (поиск по имени/хосту, мультиселекты по моделям, версиям ROS, статусам бэкапа и активности с чекбоксами, поиском внутри выпадающих списков, кнопками «Выбрать все»/«Сбросить» и сохранением состояния в `sessionStorage`).
  - Устранено мерцание таблицы при обновлениях и прекращен избыточный холостой поллинг таблицы.
  - Колонки оборудования со строгим вертикальным расположением модели над версией прошивки.
  - Компактная колонка статуса бэкапа с подробными тултипами и защитой от переполнения ячеек.
  - Статус Git в виде отдельной KPI-карточки со скрытием кнопки Push при отсутствии непушнутых коммитов.
  - Умное отображение пароля шифрования бэкапа только при явном включении шифрования на устройстве.
  - Компактные кнопки шапки («По умолчанию», «Добавить») без выпадания за границы контента.
  - HTTP Basic Auth.
- [x] **Telegram оповещения**: HTML-отчеты со сводной статистикой.
- [x] **Импорт оборудования**: успешный сбор и интеграция 125 активных устройств из `of-linux21` в рабочий `config.json`.
- [x] **Docker и Systemd**: готовые конфигурации для развертывания.
- [x] **Технический аудит и надежность**:
  - Надежный асинхронный запуск массового бэкапа в фоновой горутине под `appCtx`, предотвращающий отмену контекста HTTP-клиентом.
  - Атомарная защита от параллельных повторных запусков бэкапа (`isRunning atomic.Bool`).
  - Полное отсутствие гонок данных (`go test -race ./...` чист).
  - Безопасное глубокое клонирование конфигураций `RouterConfig.Clone()`.
  - Добавление `without-paging` во все CLI print-запросы RouterOS.
  - Поддержка CHR и x86 виртуалок при отсутствии RouterBOARD.
  - Защита от Path Traversal при формировании путей на диске.
