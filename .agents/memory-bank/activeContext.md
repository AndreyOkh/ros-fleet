Кнопка `Push` отображается только тогда, когда локальный репозиторий опережает удаленный (`Ahead > 0`) или произошла ошибка отправки (`LastError != ""`). Если коммиты отправлены, кнопка скрывается и выводится статус «• Отправлено».

    - Колонка «Оборудование» структурирована: модель всегда отображается сверху, версия RouterOS строго под ней с отступом 5px (`display: flex; flex-direction: column; gap: 5px;`), длинные названия моделей обрезаются через ellipsis с полным отображением в тултипе `title`.

    - Все кнопки в шапке дашборда и бейдж Git приведены к строго единой высоте (38px), запрещен перенос строк (`white-space: nowrap`), устранены визуальные перекосы сетки.
  - **Исправление ошибки записи файлов при монтировании в Docker (EBUSY / "device or resource busy"):**
    - Выявлена причина ошибки при переключении активности роутера или сохранении настроек в Docker: при bind-mount одного файла (`./config.json:/app/config.json:rw`, `./state.json:/app/state.json:rw`) целевой файл в Linux является точкой монтирования, из-за чего системный вызов `rename()` возвращает `EBUSY`.
    - В `internal/config`, `internal/state` и `internal/storage` реализован умный фолбэк: при ошибке `rename()` данные открываются через прямой дескриптор с `O_TRUNC` и сбрасываются на хост через `fsync`, гарантируя корректное сохранение файлов как в обычном окружении, так и внутри контейнеров Docker.
  - **Отправка изменений в Git через Access Token:**

    - Поддержана автоматическая адаптация аутентификации под различные провайдеры (GitHub `x-access-token`, GitLab `oauth2`, Bitbucket `x-token-auth`, Gitea), а также автоматическая конвертация SSH-синтаксиса (`git@host:owner/repo.git`) в HTTPS при указании токена.
