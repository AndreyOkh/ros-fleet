# Project Brief: ros-fleet

## Overview
**ros-fleet** (`github.com/AndreyOkh/ros-fleet`) — высокопроизводительная, надежная система централизованного управления парком сетевого оборудования MikroTik RouterOS (v6 и v7), автоматического резервного копирования и версионирования конфигураций в Git на **Go 1.27** с использованием стандартного пакета **`encoding/json/v2`**.

## Core Goals
1. **Автономность и надежность:** Резервное копирование бинарных `.backup` и текстовых `.rsc` экспортов сетевых устройств MikroTik по расписанию и по требованию.
2. **Минимализм и Zero-Build:** Работа как единый бинарник без CGO, Node.js, npm, webpack или тяжелых внешних библиотек.
3. **Чистый Git-дифф:** Нормализация текстовых экспортов конфигурации (удаление динамических временных меток из заголовков RouterOS) для предотвращения ложных коммитов в Git.
4. **Информативный Web UI:** Zero-build веб-дашборд на Go `html/template` + HTMX с поддержкой темной/светлой темы, модальными окнами управления роутерами и статусом Git.
5. **Телеметрия и персистентность:** Сбор информации о моделях, версиях RouterOS, CPU, памяти и Uptime с сохранением в `state.json` (`sync.RWMutex`) с атомарной записью.
